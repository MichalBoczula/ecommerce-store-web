# Storefront state icons

`catalog-empty.svg` and `catalog-error.svg` are exact exports from the approved Figma nodes 15:1793 and 15:1807 in file ZRkPrMyrqoNcVn93FMUh07. They retain their 24 × 24 SVG dimensions and state colors. The source icons are Google Material Design Icons (`shopping_cart` and `close`), distributed under Apache License 2.0; see LICENSE and https://github.com/google/material-design-icons.

`payment-pending.svg`, `payment-success.svg` and `payment-failed.svg` are exact exports from Figma nodes 15:1865, 15:1879 and 15:1893. The pending/paused states reuse the same receipt icon, and confirmed/invoice-ready states reuse the same check icon. Each export retains its intrinsic 24 × 24 dimensions and original state color. These Google Material Design Icons (`receipt_long`, `check`, `close`) use the same Apache License 2.0 included here.
